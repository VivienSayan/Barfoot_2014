This is a simple hand-made toolbox to familiarize with classical definitions regarding Lie groups. The closed-form formula can be found in the following reference:

Barfoot, T. D., & Furgale, P. T. (2014). Associating uncertainty with three-dimensional poses for use in estimation problems. IEEE Transactions on Robotics, 30(3), 679-693.

The code "main_unit_tests.m" verifies if some properties are satsified to validate the formulas.

Do not hesitate to report any mistake !
